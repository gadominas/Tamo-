# Blueprints

Dienynas+ (Tamo+) follows the shared blueprints in https://github.com/gadominas/app-blueprints.
The script's `BLUEPRINTS` block is the source of truth; this table mirrors it and adds deviations.

| Blueprint | Version | Since app version | Deviations |
| --- | --- | --- | --- |
| [in-app-updates](https://github.com/gadominas/app-blueprints/blob/in-app-updates-v1.0.0/blueprints/in-app-updates.md) | 1.0.0 | 1.4.0 | Release highlights may carry Lithuanian text (`lt`), shown when the app language is Lithuanian |
| [settings](https://github.com/gadominas/app-blueprints/blob/settings-v1.0.0/blueprints/settings.md) | 1.0.0 | 1.6.0 | The sheet follows the app language (Lithuanian labels for Appearance and all sections); the default headline font is rounded (SF Pro Rounded) rather than sans serif; sheet CSS is scoped under `#cfgsheet` because the app already uses `.seg`, `.sheet` and `.chip`; the old colour names are kept as aliases of the shared tokens, plus app colours `--mark`, `--markInk` and `--green` per palette; the Tiny layout is done with CSS on the existing rows (tap a row to expand); per-child grade scales live in `settings.gradeScales`; account actions (switch child, sign-in, sign out) sit in an Account section |
| [ai-configuration](https://github.com/gadominas/app-blueprints/blob/ai-configuration-v1.0.0/blueprints/ai-configuration.md) | 1.0.0 | 1.5.0 | The app's own Ask limits are tunables in the Settings registry; AI settings and usage live in `dienynas-plus-ai-settings.json` and `dienynas-plus-usage.json`; `aiCall` also accepts a whole conversation for Ask; no background AI jobs, so “What AI does” has no switch; the AI sheet's wording is English in both languages |
| [launch-screen](https://github.com/gadominas/app-blueprints/blob/launch-screen-v1.0.0/blueprints/launch-screen.md) | 1.0.0 | 1.7.0 | The name uses the app's `--display` font (`--sp-font`); the sweep is the teal homework dot, sliding in from `--sp-sweep-from: -40px`; the faint day dots are Frame circles (r 3.5 at the Frame's 7 stroke, so they read as solid dots); one extra rule, `.splash .spDetail{fill:var(--sp-bg)}`, because the plus is cut out of the blue day; the tagline follows the app language ("Žinutės. Užduotys. Ramybė." in Lithuanian); the app reloads its page when fresh data arrives, so the screen shows once per run on the first page (cached diary or "Loading…") and later page loads wait until it has faded (`afterSplash`); the app's refresh-button class `spin` became `busy` (keyframes `turn`) so only the launch screen uses `sp` names |
| [widgets](https://github.com/gadominas/app-blueprints/blob/widgets-v1.0.0/blueprints/widgets.md) | 1.0.0 | 1.8.0 | `WIDGET.words` is a getter, because `WIDGET` is built before `loadSettings()` reads the language (Lithuanian or English, like every widget string); the Widget group keeps the app's `widgetRefreshMin` default of 20 min (15–120, step 5) and its extra `widgetCacheMin`; `widgetModel()` asks TAMO when the current child's data is older than `widgetCacheMin`, within one TAMO request time limit (`requestWait`) in total, and then saves only the widget snapshot (never the app's cache) so the next widget run reuses it, falling back to the snapshot when TAMO doesn't answer in time; the snapshot keeps one entry per child (lesson times and subjects, homework due dates, message dates and unread flags; no grades, no message text) so the widget parameter can pick a child, and is also saved after the Shortcuts check and emptied on sign-out and on changed sign-in details; before the first save the widget reads the app's cache; the entry point keeps the app's test guard (`__DIENYNAS_TEST__`) and the key migration moved into `main()`, so widget runs migrate nothing; rows after the counts show the rest of today's lessons with the lesson number as the icon; when today's lessons are over the caption names the next school day's first lesson |
